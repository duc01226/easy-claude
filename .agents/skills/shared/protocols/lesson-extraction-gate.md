## Continuous Improvement — Lesson Extraction Gate

Add `Analyze AI mistakes & lessons learned` to non-trivial tasks. Extract the root reasoning failure, generalize to at least three contexts, remove incident specifics and consolidate duplicates. Recommend only a project convention or a universal best-practice protocol worth reading on everyday work — skip rare AI-agent quirks, one-off incidents and details of the current task. Skip nonrecurring lessons. Route a recurring one structure-first and take the first tier that fits: make the mistake impossible by design (a type, a wrapper, a structure), else an automatic check (a lint rule or architecture test whose message names the fix, landing with a frozen baseline of existing violations), else a test, else a hook; prose (a review-skill rule or a `$learn` lesson) comes last. Propose a structural tier as a change for the user to approve; for prose, ask the user to run `$learn`; never silently self-edit instructions.
