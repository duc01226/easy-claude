Use `/rich-report` in Claude Code or `$rich-report` in Codex to turn a topic or evidence into a visual report with a sticky table of contents and a glossary. The skill uses a private Site in Codex or a private Artifact in Claude when available. It saves standalone HTML under workspace `tmp/reports/` on other hosts or when native delivery is unavailable.
