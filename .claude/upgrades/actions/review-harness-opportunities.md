Focused and workflow-based change reviews now classify the reviewed diff and assess what could prevent the same class of problem. The workflow runs the assessment alongside correctness review and includes the result in pull request evidence. You can also ask the harness opportunities skill to assess an explicit historical change.

Approved checks use the project's existing verification commands, with affected and full scopes where supported. An authorized fix loop can draft a check or lesson. Activation requires the owner's approval and evidence that the proposed check detects the bad example, permits the valid example and handles any legacy baseline.
