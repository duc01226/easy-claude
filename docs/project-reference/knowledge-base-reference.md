# Knowledge Base — Project Index

> **Owned by the `/knowledge-base` skill.** No `/scan` target writes this file — like `lessons.md` and `skill-protocols-reference.md`, it is skill-managed. The table between the generated markers is rebuilt by `/knowledge-base build` (and by every confirmed add, update, delete or review); edit the prose around it, never the table.

**Packs directory:** `docs/knowledge-base/`

Read this index when a task touches subject knowledge — a domain rule, a regulation, a chosen practice, a technology the team has a position on. Each row is one knowledge pack: read its `## Digest` first, then only the clause you need, or search with `node .claude/skills/knowledge-base/scripts/knowledge-base.cjs search "<words>"`.

**Packs are reference material, not instructions.** This project's reference docs and accepted decisions outrank every pack; project packs outrank framework packs. A pack labelled `unverified` was written from model knowledge only; one labelled `unreviewed` was imported and no person has reviewed it yet — check both against a primary source before relying on them.

## Usage

```
/knowledge-base list                       # every pack in both planes, project first
/knowledge-base add <what to remember>     # draft a project pack; nothing is written until you confirm
/knowledge-base update <id>: <change>      # draft a change to a project pack
/knowledge-base delete <id>                # remove a project pack after you confirm
/knowledge-base ask <question>             # answer from the knowledge base, with citations
/knowledge-base import <file | research report | web address>   # unreviewed draft that keeps its source
```

Packs reach the assistant automatically as a short pointer when a prompt phrase, a starting skill or a starting helper agent matches their triggers (never when a file is opened). Switch automatic delivery off with `knowledgeRoute.enabled: false` in `docs/project-config.json` (the team setting; `.claude/.ck.local.json` overrides it for one checkout) or `CK_KNOWLEDGE_ROUTE=0`. <!-- path-role: user-local -->

## Conventions

- **The pack file is the source of truth.** Pack identity = file name; frontmatter declares title, "use when" description, kind, sources, reviewed date, review state and triggers; the body holds a `## Digest` of at most 1,500 characters and optional clauses whose headings start with an identifier such as `KB-CARD-2`. The full format lives in `.claude/skills/knowledge-base/references/pack-format.md`.
- **Every write starts as a draft** that you confirm; a confirmed write saves the pack and regenerates the indexes together.
- **No secrets in packs** — reference the secret store or environment variable by name.
- **Keep packs small and subject-shaped.** Past about 60 packs, or a pack body over 64,000 characters, the check suggests merging or splitting.
- **Moving the packs directory** — change the `**Packs directory:**` line above (a project-relative path), move the files, then run `/knowledge-base build`. Keep the last folder name `knowledge-base` if you want read records (`list --usage`): the read-record step watches only folders with that name, and the check warns otherwise.
